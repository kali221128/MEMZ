## 1. 概述

**MEMZ**（俗称"彩虹猫病毒"，英文常称 *MEMZ Trojan* / *MEMZ Joke Malware*）是 2016 年公开传播的 Windows 平台恶意程序。其核心特征为**大量恶搞型 Payload + 覆盖主引导记录（MBR）**，在娱乐化外观之下具备**不可逆的系统破坏能力**。

按传播方式划分，MEMZ **不具备自我复制与网络传播能力**，需用户主动执行，因此在分类上更接近 **Trojan / Joke Malware（木马 / 玩笑类恶意软件）**，而非严格意义上的"病毒"。但其 MBR 写入行为使其实际危害远超普通恶作剧程序。

| 属性 | 说明 |
|---|---|
| 常见名称 | MEMZ、彩虹猫病毒、Nyan Cat Virus |
| 分类 | Trojan / Joke Malware / Bootkit（附带引导级载荷） |
| 目标平台 | Windows（x86 / x64） |
| 传播方式 | 无自动传播，依赖用户手动执行 |
| 持久化 | 写入 MBR 的引导级 Payload |
| 主要危害 | MBR 覆盖、数据破坏（破坏版）、系统无法启动 |
| 网络行为 | 基本无（无 C2、无回连） |
| 首次公开 | 2016 年 |

> **分类学说明：** 严格意义上 MEMZ **不是"病毒"**——它无自我复制机制、无文件感染/寄生行为、无网络或介质传播能力。更准确的定位是**携带引导区破坏载荷的木马/玩笑程序**。"病毒"为网络俗称。

## 3. 历史背景

MEMZ 由作者 Leurak 制作，并投稿给知名恶意软件分析类内容创作者 **danooct1** 的 *Viewer-Made Malware*（观众投稿恶意软件）系列。该系列本身以**分析、演示、教育**为目的，并在隔离环境中运行样本，MEMZ 因此获得大量曝光。

其标志性的"彩虹猫（Nyan Cat）动画引导画面"——在 MBR 被覆盖、系统重启后由自写引导代码直接在屏幕上渲染——使其成为互联网上辨识度最高的恶意软件之一，也常被用于网络安全入门科普中说明**"引导区破坏"**的概念。

> **重要提示：** 作者公开作品的语境是演示与教育，**不代表该样本可以安全运行**。原版即会造成 MBR 被覆盖，破坏版会造成数据不可恢复的损毁。

## 4. 版本与变体

据公开资料，作者发布过多个版本，行为差异显著：

| 版本 | 主要差异 |
|---|---|
| **MEMZ**（原版） | 完整恶搞 Payload 序列 + 末尾覆盖 MBR；重启后进入彩虹猫引导画面，系统无法正常启动 |
| **MEMZ-Destructive** | 破坏性进一步加强，会对磁盘文件进行覆盖/损毁，数据恢复难度极高 |
| **MEMZ-Clean** | 仅保留彩虹猫相关的视觉/声音 Payload，**不写入 MBR**，破坏性大幅降低，通常用于演示 |
| **MEMZ-Trojan** | 原版体系的变体版本，公开技术细节相对较少，建议以原始发布页与专业分析报告为准 |

> **⚠️ 第三方改包风险：** 网络上存在大量**二次打包、改名、加壳**的第三方版本，行为可能与上述描述不符，甚至叠加了真实的信息窃取木马。任何来源不明的"彩虹猫"程序都应视为高危样本。
